# Список броней: фильтры и Excel

Доступ: JWT администратора в заголовке `Authorization: Bearer <token>`.

`GET /api/admin/reservations` без параметров по-прежнему возвращает
`{"reservations": [...]}` со всеми прежними полями. Параметры необязательны,
комбинируются через AND и применяются одинаково к JSON и Excel.

| Параметр | Значение |
|---|---|
| `event_id` | Положительный ID события |
| `session_id` | Положительный ID сеанса |
| `user_id` | Положительный ID пользователя |
| `date_from`, `date_to` | Даты сеанса в формате `YYYY-MM-DD` |
| `booked_from`, `booked_to` | Даты создания брони в формате `YYYY-MM-DD` |
| `is_paid` | `true`, `false`, `1`, `0` |
| `is_cancelled` | `true`, `false`, `1`, `0` |
| `payment_status` | `unpaid`, `pending`, `waiting_for_capture`, `succeeded`, `canceled` |
| `q` | Подстрока ФИО, телефона или email, без учёта регистра, до 255 символов |
| `format` | `json` по умолчанию; `xlsx` для скачивания Excel |

Границы дат включительны: `date_to=2026-11-16` включает весь день 16 ноября.
Используется время, сохранённое в базе, без дополнительного преобразования часового пояса.
`unpaid` соответствует отсутствию связанного платежа или его статусу `unpaid`;
флаг `is_paid` фильтруется отдельно. Неизвестный ID даёт пустую выборку.
Некорректные значения фильтров и обратные диапазоны дат возвращают HTTP 400 с `message`.

Примеры:

```http
GET /api/admin/reservations?event_id=12&date_from=2026-11-01&date_to=2026-11-30&is_paid=true
GET /api/admin/reservations?event_id=12&date_from=2026-11-01&date_to=2026-11-30&is_paid=true&format=xlsx
GET /api/admin/reservations/export?event_id=12&is_cancelled=false
```

`/reservations/export` — альтернативный адрес выгрузки с теми же фильтрами.
Файл `reservations.xlsx` содержит все подходящие брони, по возрастанию ID:
событие, сеанс и его дату, место, пользователя, контакты, участников, дату
создания, оплату и отмену, статус платежа, стоимость за участника и сумму.
Сумма рассчитывается из стоимости сеанса и количества участников, как в JSON.
Телефоны и пользовательские строки сохраняются как текст; суммы — как числа,
даты — как даты Excel. Включены автофильтр и закрепление строки заголовков.
Пустая выборка даёт файл с заголовками. При превышении лимита строк Excel
сервер просит уточнить фильтры (HTTP 400).

Во встроенной Flask-админке добавлены поля фильтрации и кнопка Excel.
Кнопка выгружает по текущим значениям полей; «Применить» обновляет список.
Отдельной Vue-админке нужно передавать такие же query-параметры, получать
ответ как Blob и скачивать его. Источники Vue в ветке `main-backend` отсутствуют.
