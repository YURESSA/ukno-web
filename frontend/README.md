# 🎓 UKNO Frontend — Ural Knowledge Network Online

Клиентская часть веб-платформы **«Уральский клуб нового образования» (UKNO)**. Сервис предназначен для организации, публикации и бронирования образовательных и культурных мероприятий (лекций, мастер-классов, экскурсий, выставок), взаимодействия резидентов с аудиторией, продажи фирменного мерча и комплексного администрирования площадки.

## 🛠 Стек технологий

- **Фреймворк:** [Vue 3](https://vuejs.org/) (Composition API, синтаксис `<script setup>`)
- **Сборщик:** [Vite 6](https://vite.dev/) (с плагином `vite-plugin-vue-devtools`)
- **Управление состоянием:** [Pinia](https://pinia.vuejs.org/) + [`pinia-plugin-persistedstate`](https://prazdevs.github.io/pinia-plugin-persistedstate/) (сохранение сессии и токенов)
- **Маршрутизация:** [Vue Router 4](https://router.vuejs.org/) (навигационные гарды по ролям и авторизации)
- **UI-компоненты:** [Naive UI](https://www.naiveui.com/) (с фирменной темой `#F25C03` и локализацией `ruRU`)
- **Иконки:** [@vicons/ionicons5](https://www.xicons.org/#/)
- **Text редактор:** [Tiptap](https://tiptap.dev/) (`@tiptap/vue-3`, `StarterKit`, `ExtensionLink`) + [DOMPurify](https://github.com/cure53/DOMPurify) для санитизации HTML
- **Картография и геокодинг:** Интеграция с [Яндекс.Карты API](https://yandex.ru/dev/maps/jsapi/) для интерактивного выбора и отображения локаций мероприятий
- **HTTP-клиент:** [Axios](https://axios-http.com/)
- **Тестирование:**
  - Unit / Store: [Vitest](https://vitest.dev/) + `@vue/test-utils` + `jsdom` + `@vitest/coverage-v8`
  - E2E: [Playwright](https://playwright.dev/) (тестирование сценариев магазина и личного кабинета)
- **Контроль качества кода:** ESLint 9 + Prettier
- **Контейнеризация:** Docker (Multi-stage build) + Nginx

## ✨ Функциональные возможности

### 1. Публичный портал
- **Афиша мероприятий:** Каталог событий с фильтрацией по категориям, форматам проведения и возрастным категориям, поиск по названию.
- **Страница мероприятия:** Подробное описание с поддержкой богатого форматирования (WYSIWYG), расписание, информация о спикере/резиденте, интерактивная Яндекс.Карта с точным адресом места проведения и кнопка бронирования билетов.
- **Новости:** Лента актуальных новостей и событий клуба с детальным просмотром.
- **О клубе и институциях:** Информационные разделы о культурном пространстве, спецпроектах, истории бюро, команде, партнерах и реквизитах.

### 2. Магазин мерча (Shop)
- Каталог сувенирной продукции и брендированных товаров с категоризацией и полнотекстовым поиском.
- Карточки товаров с галереей изображений, характеристиками и описанием.
- Корзина с динамическим подсчетом суммы и управлением количеством.
- Список избранных товаров (Wishlist).
- Оформление заказов и отслеживание истории покупок.

### 3. Авторизация и безопасность
- Регистрация пользователей, авторизация по логину и паролю.
- Восстановление и сброс пароля по электронной почте.
- Хранение токенов авторизации и разграничение прав через навигационные хуки маршрутизатора (`beforeEach`).

### 4. Личные кабинеты по ролям
- **Пользователь (`user`):** Просмотр профиля, история личных бронирований, история заказов в магазине.
- **Резидент (`resident`):** Создание и редактирование собственных мероприятий с загрузкой медиа, форматированием описания через Tiptap и геопривязкой на карте; просмотр аналитики и статистики посещаемости.
- **Администратор (`admin`):** Полный доступ к панели управления платформой (`/panel`).

### 5. Панель администратора (`/panel`)
- Управление учетными записями пользователей и назначение ролей (`user`, `resident`, `admin`).
- Модерация событий и список всех бронирований.
- Справочники: категории, типы форматов, возрастные категории.
- Управление магазином мерча: товары, категории, рекламные баннеры, заказы.
- Управление контентом сайта: новости, команда, партнеры, проекты, история, культурное пространство, реквизиты.

### Алиасы путей (Path Aliases)
Для удобного импорта настроены псевдонимы путей в `vite.config.js` и `jsconfig.json`:
- `@/` $\rightarrow$ `src/`
- `@shared/` $\rightarrow$ `src/components/shared/`
- `@UI/` $\rightarrow$ `src/components/ui/`
- `@assets/` $\rightarrow$ `src/assets/`

## 🔐 Ролевая модель и маршруты

| Маршрут | Описание | Доступ |
| :--- | :--- | :--- |
| `/` | Главная страница | Все пользователи |
| `/events` | Афиша мероприятий | Все пользователи |
| `/events/:id` | Детальная страница события | Все пользователи |
| `/news` | Новости | Все пользователи |
| `/ukno`, `/requesits` | О клубе, реквизиты | Все пользователи |
| `/shop` | Каталог мерча | Все пользователи |
| `/shop/:id` | Товар | Все пользователи |
| `/login`, `/register` | Вход и регистрация | Гости |
| `/payment/:id` | Оплата бронирования | Авторизованные (`requiresAuth: true`) |
| `/profile` | Личный кабинет участника | Роль `user` |
| `/resident-profile` | Кабинет резидента | Роль `resident` |
| `/newEvent`, `/change-event/:id` | Создание и редактирование мероприятий | Роль `resident` |
| `/admin-profile` | Профиль администратора | Роль `admin` |
| `/panel/*` | Секции панели администратора | Роль `admin` |

## ⚙️ Переменные окружения

Создайте файл `.env` в папке `frontend` на основе `.env.example`:

```bash
cp .env.example .env
```

| Переменная | Назначение | Пример значения |
| :--- | :--- | :--- |
| `VITE_FRONTEND_URL` | Базовый URL бэкенд API | `http://127.0.0.1:5000/` |
| `VITE_YANDEX_API_KEY` | Ключ доступа к Яндекс.Картам (JavaScript API) | `your_api_key_here` |
| `E2E_BASE_URL` | *(Опционально)* Базовый URL для E2E тестов | `http://localhost:5173` |

## 🚀 Установка и запуск

### Требования
- **Node.js:** версия `18.x` или выше (рекомендуется LTS 20+)
- **npm:** версия `9.x` или выше

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
Запуск dev-сервера Vite с горячей перезагрузкой (HMR):
```bash
npm run dev
```
По умолчанию приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173).

### 3. Сборка для продакшн
Компиляция и минификация исходного кода в директорию `dist/`:
```bash
npm run build
```

### 4. Предпросмотр продакшн-сборки
Локальный запуск собранного проекта из папки `dist/`:
```bash
npm run preview
```

## 🧪 Тестирование

### Unit и интеграционные тесты (Vitest)
Для тестирования логики Pinia-сторов и компонентов используется Vitest:

```bash
# Однократный запуск всех тестов
npm run test

# Запуск в режиме отслеживания изменений (watch mode)
npm run test:watch

# Запуск с графическим интерфейсом Vitest UI
npm run test:ui

# Запуск с генерацией отчета о покрытии кода (Coverage)
npm run test:coverage
```

### End-to-End тесты (Playwright)
E2E тесты проверяют пользовательские сценарии (навигация, интернет-магазин, корзина):

```bash
# Запуск всех E2E тестов в безголовом режиме
npm run test:e2e

# Запуск интерактивного UI режима Playwright
npm run test:e2e:ui

# Просмотр последнего HTML-отчета о тестировании
npm run test:e2e:report
```

## 📐 Стандарты разработки

1. **Компоненты Vue:**
   - Использовать только **Composition API** и синтаксис `<script setup>`.
   - Имена файлов компонентов — строго в `PascalCase` (например, `ProductCard.vue`).
   - Использование компонентов в шаблонах — в `PascalCase` (`<ProductCard />`).
   - Использовать `<style scoped>` для локализации стилей компонента. Для общих цветов и отступов использовать CSS-переменные из `main.css`.
2. **Иерархия компонентов:**
   - `@UI/` (`src/components/ui/`) — атомарные переиспользуемые элементы (кнопки, алерты, инпуты, редактор).
   - `@shared/` (`src/components/shared/`) — крупные сквозные блоки (шапка, футер, интерактивные карты).
   - `src/pages/{page}/components/` — специфичные компоненты конкретной страницы.
3. **Хранилища (Pinia):**
   - Бизнес-логику, вызовы API и сохранение данных выносить в соответствующие сторы (`stores/counter.js`, `stores/shop.js`).
4. **Безопасность контента:**
   - При выводе HTML из редактора Tiptap обязательно санитизировать строку через `DOMPurify.sanitize(content)`.
